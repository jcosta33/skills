# Research

Reports behind the catalog's decisions, all written on 2026-11-05. The ADRs in
[`../adrs`](../adrs/README.md) cite them line by line, and [`../sources.md`](../sources.md) lists
the primary sources each skill line rests on.

These are research notes, not rules. Each file states its own method and verification status.
Corrections found later are recorded in the files that found them; see "Corrections" in
[engineering-meaning-empirical.md](engineering-meaning-empirical.md).

## Engineering meaning

- [engineering-meaning.md](engineering-meaning.md): the enriched review. Its §9 proposes the skill
  changes.
- [engineering-meaning-source.md](engineering-meaning-source.md): the original review as supplied
  by José, kept verbatim for verification.
- [engineering-meaning-verify.md](engineering-meaning-verify.md): citation check of the original's
  31 footnotes.
- [engineering-meaning-theory.md](engineering-meaning-theory.md): language, argument and
  requirements theory the original misses.
- [engineering-meaning-empirical.md](engineering-meaning-empirical.md): empirical evidence the
  original lacks, plus corrections to earlier files.
