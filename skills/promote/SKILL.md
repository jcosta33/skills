description: Make a lesson or working document a durable project record in its existing home. Use when something learned or drafted in a session must outlive it. Do not use for unverified observations or for moves between scratch locations.

# Promote

- Use the project's existing home: decision record, issue, test, runbook, or docs. Offer real
  destinations as a choice; never invent one.
- Move, not copy, unless asked. Commit only when chosen; never push. Return the durable path.
