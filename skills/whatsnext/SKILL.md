# What's next

From current repository, issue, and branch state, not memory, recommend the single highest-value
next step: the step, its reason, what else it changes, and its stop condition.
Then give at most two alternatives, one line each; include stopping here when that is defensible.
If the step needs nothing from the user, say so and start it. If it needs a decision the user owns,
ask for that one decision.
