# Settle

1. Restate the question without the answer the asker seems to prefer, and say what evidence would
   decide it. Decide on that evidence before weighing the preference.
2. Settle what code, tests, project precedent, or primary docs can decide, and state the decision.
   Demand more proof the less reversible the choice. If the deciding evidence is out of reach here,
   say so.
3. Ask the user only when the plausible readings lead to different actions, and only the single
   question that most decides the work. Ask it as a choice: native picker, else a numbered list.
   Recommendation first, three options (two if binary), one reason and cost each, plus Other.
4. Freeze only the work that depends on the answer.
