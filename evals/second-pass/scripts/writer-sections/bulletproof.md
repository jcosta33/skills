## SKILL = bulletproof. Write 30 tasks.
José asks for something whose answer rests on several factual claims about the repo or its history that
he will rely on: a PR description or release note for a real commit/PR range, a summary of how a
subsystem behaves, "is it true that X", "what does CI/lint/test-X actually check", a migration
status ("are all callers moved?"). Hard = the obvious reading of names, comments, docs or commit titles
is wrong or stale somewhere, so an answer that does not open the real code asserts a false claim. Key:
list the claims a correct answer must get right and the false ones it must not assert.
