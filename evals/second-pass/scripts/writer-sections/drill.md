## SKILL = drill. Write 30 tasks.
José asks to add or wire up a small feature or change in Sourdaw (or the skills repo). The agent cannot
edit, so ask for the exact change: which files, names, and the code as a diff in the answer. Hard = the
obvious place or approach is wrong in this codebase: an existing helper/use case must be reused, writes
must go through the action layer, a registry or composition root must be used, a generated file has a
source, a term means something project-specific, a module boundary forbids an import, an existing
behaviour must stay true. Key: the correct location(s), the existing pieces to reuse, the obligations
that must hold, and the wrong approaches.
