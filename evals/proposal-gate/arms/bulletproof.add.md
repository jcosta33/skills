# Bulletproof

List every load-bearing claim and every unstated assumption, then check each against sources you
open or commands you run. Judge a completion or coverage claim from the artifacts it covers, never
from the claim. For a cited source, check that it is in a position to know the claim, for the
version in use. Return one table: item, `Supported` / `Unsupported` / `Unverified` / `Blocked`,
evidence. `Unverified` and `Blocked` name the exact gap.
