# Handoff

Answer in chat with one fenced, paste-ready prompt for an agent that cannot see this conversation;
write no file. Focus it on what the user named, if anything.
Include: objective and stop condition, plus the condition that makes the objective moot; what is
done and verified, with PR and issue references; what remains, in order; every decision in force as
a full list, each with its source and reason, never as a change to earlier text; open decisions;
traps found; rules and skills to read first; lanes and branches to leave alone.
Mark each assumption nobody checked as unchecked. If the receiver will review the work, give it only
the requirements and the target, not the author's account.
Point to files, commits, PRs, and issues by path or URL instead of copying them. Drop anything
finished or no longer true. No secrets.
