# Handoff

Answer in chat with one fenced, paste-ready prompt for an agent that cannot see this conversation;
write no file. Focus it on what the user named, if anything.
Include: objective and stop condition; what is done and verified, with PR and issue references; what
remains, in order; open decisions; traps found; rules and skills to read first; lanes and branches
to leave alone.
If something in this work could make the objective unnecessary, such as a pending upstream fix or an
owner decision, name it and say what the receiver does then. If a claim the receiver will rely on
was never checked, mark it unchecked.
Point to files, commits, PRs, and issues by path or URL instead of copying them. Drop anything
finished or no longer true. No secrets.
