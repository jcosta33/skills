# Debloat

1. Before editing, list every fact, rule, command, identifier, warning, and required heading the text
   carries.
2. Give each item one home. Cut duplicates, recaps, hedges, pleasantries, and sentences that change no
   action or decision.
3. If the text instructs an agent, write each rule as "If C, do X" with no hedge, put the most
   important rules first, and flag rules that contradict each other or no longer match the code. If
   more than ten load-bearing rules remain, name the ones you would cut instead of cutting them.
4. Check the result against the list and restore anything missing.
